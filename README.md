# Java 程式作品集

## 使用技術

- **語言：** Java
- **資料結構：** `ArrayList`、`LinkedList`、`Stack`
- **多執行緒：** `Thread`、`start()`、`join()`
- **圖形化介面：** Java Swing、NetBeans GUI Builder
- **網路連線：** HTTPS、TCP Socket、`ServerSocket`、`URLConnection`
- **資料處理：** `InputStream`、`OutputStream`、檔案讀寫

## 執行方式

各資料夾的程式為獨立練習，可依檔案名稱個別編譯與執行。使用前請先安裝 JDK，並確認終端機可以使用 `javac` 與 `java` 指令。

以下以「排序串列」為例，在專案根目錄執行：

```bash
cd "資料結構與演算法/排序串列"
javac -encoding UTF-8 MI2C_HWK3_412631474_01.java
java MI2C_HWK3_412631474_01
```

**圖形化介面：** 執行 Swing 程式需要桌面圖形環境；`.form` 是 NetBeans GUI Builder 的表單設計檔，與同名 `.java` 放在一起保存。

**檔案編碼：**「網頁圖片擷取」已改為 UTF-8；「點餐數量管理」仍保留原始 MS950 編碼，編譯時可指定 `javac -encoding MS950`。

**網路程式：** 兩個作品已改為使用相對目錄，可由命令列指定網址、資料夾、IP 與連接埠。完整操作步驟請參考各作品內的 README：

- [網頁圖片擷取：編譯、執行與本機示範](網路程式設計/網頁圖片擷取/README.md)
- [Socket 檔案傳輸：Server／Client 啟動方式](網路程式設計/Socket檔案傳輸/README.md)
